HealthcareComm — კონტაქტებისა და ჩატის გამართვის ინსტრუქცია
====================================================================

ნაბიჯი 1: Supabase-ის გამართვა (SQL Editor)
--------------------------------------------------------------------
1. გადადით თქვენს Supabase პროექტში.
2. მარცხენა მენიუდან გახსენით "SQL Editor" (ტერმინალის იკონი).
3. გახსენით ფაილი "contacts_setup.sql", დააკოპირეთ მთლიანი კოდი და ჩასვით Supabase SQL Editor-ში.
4. დააჭირეთ "Run" (გაშვებას).
   -> ეს შექმნის contacts ცხრილს, ინდექსებს და RLS უსაფრთხოების წესებს.


ნაბიჯი 2: ფრონტენდის ფაილების განთავსება პროექტში
--------------------------------------------------------------------
თქვენს პროექტში (Healthcare_Comm-main) ჩაანაცვლეთ ფაილები შესაბამის ფოლდერებში:

1. directory_page.tsx:
   -> ჩააგდეთ ფოლდერში: app/directory/
   -> დაარქვით: page.tsx
   (საბოლოო მისამართი: app/directory/page.tsx)

2. messages_page.tsx:
   -> ჩააგდეთ ფოლდერში: app/messages/
   -> დაარქვით: page.tsx
   (საბოლოო მისამართი: app/messages/page.tsx)

3. Navbar.tsx:
   -> ჩააგდეთ ფოლდერში: components/
   (საბოლოო მისამართი: components/Navbar.tsx)

4. MobileNav.tsx:
   -> ჩააგდეთ ფოლდერში: components/
   (საბოლოო მისამართი: components/MobileNav.tsx)


რას ცვლის ეს განახლება:
--------------------------------------------------------------------
- ჩატში აღარ გამოჩნდება ყველა იუზერი — გამოჩნდებიან მხოლოდ ის კოლეგები, ვისაც დაიმატებთ დირექტორიიდან, ან ვინც მოგწერთ.
- დირექტორიაში (კოლეგების გვერდზე) დამატების ღილაკი იმუშავებს შეუფერხებლად და შეცდომების გარეშე.
- დამატებული კოლეგის გასწვრივ ჩნდება ღილაკი "ჩატი" და "წაშლა".
- ნავბარში დაემატა "კოლეგები" ლინკი სწრაფი გადასვლისთვის.
